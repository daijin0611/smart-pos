# 支付方式重构 - 前端对接变动文档

## 1. 支付类型编码映射（全局影响）

所有涉及 `paymentType` 字段的接口，编码值变更如下：

| 旧编码 | 旧含义 | 新编码 | 新含义 |
|--------|--------|--------|--------|
| 0      | 微信   | 0      | 扫码   |
| 1      | 支付宝 | —      | 已合并进扫码(0) |
| 2      | 现金   | 1      | 现金   |
| 3      | 会员卡 | 5      | 会员卡 |
| 4      | 优惠券 | —      | 已合并进扫码(0) |
| 5      | 美团   | 4      | 美团   |
| 6      | 抖音   | 3      | 抖音   |
| 99     | 未知   | —      | 已合并进扫码(0) |
| —      | —      | 2      | POS（新增） |

**前端枚举建议更新为：**

```ts
enum PaymentType {
  QR = 0,         // 扫码
  Cash = 1,       // 现金
  POS = 2,        // POS
  DouYi = 3,      // 抖音
  MeiTuan = 4,    // 美团
  MemberCard = 5, // 会员卡
}
```

---

## 2. 结算接口 `POST /order/settle-order`

**请求体 `paymentInfoList[].paymentType`** 需传入新编码值（见上表）。

无结构变更，仅编码值变更。

---

## 3. 销售汇总接口 `POST /order/summary`

**响应体 `OrderSummaryVO` 字段变更：**

| 删除的旧字段                  | 新增字段             | 类型        |
|-------------------------------|----------------------|-------------|
| `wechatPayment`               | `qrPayment`          | BigDecimal  |
| `alipayPayment`               | —                    | —           |
| `bankCardPayment`             | `posPayment`         | BigDecimal  |
| `electronicCouponPayment`     | `douyinPayment`      | BigDecimal  |
| `otherPayment`                | `meituanPayment`     | BigDecimal  |
| `membershipCardPayment`       | `memberCardPayment`  | BigDecimal  |

充值字段不变：`cashRecharge`、`wechatRecharge`、`otherRecharge`。

---

## 4. 订单分页查询 `POST /order/page`

**请求体 `OrderPageQuery.paymentType`** 筛选值需用新编码。

**响应体 `OrderInfoVO.payments[].paymentType`** 返回新编码值。

无结构变更，仅编码值变更。

---

## 5. 订单详情/小票接口 `GET /order/query-by-id/{orderId}`

**响应体 `OrderReceiptVO.payments[].paymentType`** 返回新编码值。

无结构变更，仅编码值变更。
